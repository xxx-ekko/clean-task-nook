# Todo App - Certification Project

A simple, fast, and modern Todo application built as part of a certification exercise.

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Data persistence using LocalStorage

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Generated with [Lovable](https://lovable.dev)

## Deployment

This project is live and deployed using GitHub Pages.
